# Что пробовали при обучении модели

Разовое сравнение вариантов, сделано 23.09.2026. Все варианты проверены одинаково: январь 2026
в обучение не входил, прогноз строился по датам выпуска с 31.12.2025 по 30.01.2026 через
previous-runs Open-Meteo, так же, как работает агент. Числа взяты из прогонов `model/train.py`
в тот день; флагов для воспроизведения отдельных вариантов в коде нет, `python -m model.train`
воспроизводит только оставленный вариант. Время обучения зависит от загрузки машины.

Первая версия училась только на архиве самых свежих прогнозов. На январе её MAE был на уровне
кривой мощности, хотя на архивных прогнозах тех же январских часов модель точнее кривой
(0,1405 против 0,1495). Отсюда гипотеза: модель учится на лучшем прогнозе, а работает на прогнозе
за одни-двое суток, который грубее. Правило приёмки для попытки: новая версия остаётся, если MAE p50
на январе ниже и покрытие p10–p90 не хуже, чем у первой версии.

Выводы. Главный выигрыш дали обучающие данные: прогнозы за сутки и за двое суток в обучении.
Новые признаки без этих данных MAE не снизили (вариант а2). Размер листа и ранняя остановка выбраны
по тому же январю, на котором идёт проверка, и дают разницу в тысячных долях; этот выигрыш может быть
случайным. Покрытие выросло выше замысла в 80%: коридор теперь шире, чем нужно, и p10 с p90 стоит
откалибровать на следующем шаге.
