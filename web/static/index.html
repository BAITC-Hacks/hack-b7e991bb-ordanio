Как работает расчёт
Доступны даты выпуска с 31.01.2026 по 28.02.2026. Прогноз строится на двое суток, следующих за датой выпуска, по часам, в долях номинальной мощности: 0 — турбина стоит, 1 — работает на полную. Время местное (UTC+5). Прогон всего февраля пишет сводки дней по шаблону; сводка от модели OpenAI строится для одного дня по кнопке «Сформировать прогноз» (при наличии ключа).
